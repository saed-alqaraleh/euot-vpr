# Third-party asset rights and redistribution decision

**No third-party datasets, upstream pretrained checkpoints, or bundled photographic images are redistributed.** The supplied ZIP's provenance labels are useful but insufficient to establish every source-image right and attribution obligation.

| Asset | Source | Decision | Reason |
|---|---|---|---|
| MSLS raw image corpus | https://github.com/mapillary/mapillary_sls | **Not included** | The repository's MIT notice covers software. Mapillary's public-imagery help describes CC BY-SA with image-specific attribution, but this does not itself establish rights and attribution records for rehosting the particular benchmark image archive. Retrieve from the official provider under current terms. |
| Gardens Point Walking day/night images | https://open.qcr.ai/dataset/day-night-lateral/ | **Not included** | An openly downloadable Zenodo record exists (10.5281/zenodo.4590133), but the accessible rights field does not specify an image-reuse license; redistribution permission for these pairs remains unverified. |
| SALAD source and pretrained DINOv2/SALAD weights | https://github.com/serizba/salad | **Not included** | Upstream source is GPL-3.0; pretrained checkpoints are made available separately. This package links to upstream rather than vendoring code or weight files; this avoids claiming any inferred checkpoint redistribution right. |
| `grace_hopper_jpg` from Matplotlib sample data | https://matplotlib.org/stable/project/license.html | **Not included** | Historical portrait rights may be permissive, but an asset-specific chain of title/credit was not documented in the uploaded bank. |
| `texlive_pic_jpg` and `texlive_pic16_png` | TeX Live pdftex examples | **Not included** | A public sample file is not the same as verified redistribution permission for an embedded resized asset. License and provenance must be established per sample. |
| `libreoffice_sand_png` and `libreoffice_intro_png` | LibreOffice gallery/UI assets | **Not included** | Archive describes MPLv2.0 but does not include original notices or verify whether exact images and generated crops are covered by that license. Source notices and conditions must be checked. |
| Trained EUOT-VPR `.pt` heads, PCA-128/k-means control and controlled model `.npz` | Fitted outputs from the study | **Included as author-fitted evidence** | Not upstream pretrained weights; these experimental artifacts are not covered by the software MIT license. Check any independent benchmark or upstream conditions before redistribution. |
| Per-query binary retrieval hits, per-query controlled diagnostics | Original experimental outputs | **Included as author-fitted evidence** | Derived measurements rather than image content; check each benchmark's provider-specific conditions. |

The withheld image bank was named `bundled_natural_image_bank.npz` and had SHA-256 `df2a6f0a0567e77c1d5753c47a90ac1ba862ecdfd38f7a858821c199e21dcb47`; it contained five downsampled 160×160 RGB assets. The controlled implementation uses that hash to refuse nonidentical image carriers. To rerun the benchmark exactly, obtain and use a copy of the **same** bank only when permission is established. Replacing carriers produces a *new* experiment and is not an exact replication.

**Rights and replay qualifications:** The MIT license covers original EUOT-VPR software only. The author-fitted heads and derived per-query records are preserved as evidence, and their provider-specific sharing restrictions should be independently reviewed. The five photographic assets remain excluded; obtaining their rights is necessary only to republish the image bank. Exact full image-level replay also requires the ordered MSLS manifest and matching SALAD model revision. Do not present permission as verified when only a broad upstream project license is known.

Rights sources checked 2026-11-15: [Mapillary SLS code license](https://github.com/mapillary/mapillary_sls/blob/main/LICENSE); [Mapillary public imagery and attribution guidance](https://help.mapillary.com/hc/en-us/articles/115001770409-CC-BY-SA-license-for-open-data); [Gardens Point Zenodo data record](https://zenodo.org/records/4590133); [SALAD GPL-3.0 license](https://github.com/serizba/salad/blob/main/LICENSE) and [upstream model instructions](https://github.com/serizba/salad). These references establish the stated *upstream* license information, not item-by-item permission to rehost withheld assets.
