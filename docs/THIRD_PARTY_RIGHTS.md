# Third-party asset rights and redistribution decision

## File-class assessment for a public release

**Current publication status:** The GitHub repository and its `1.0.0` release are public. That release already includes 97 `.pt` checkpoints, one trained-parameter `.npz` file, and one MSLS-derived query-grouping JSON listed below. A decision to **withhold from a conservative public snapshot** means the asset would be omitted from a *separately prepared, clean-history edition*; it does **not** mean it is absent from the current published release. No documented blanket authorization for further redistribution of those particular records has been established by this review.

The sources below were reviewed on 2026-11-15. **An upstream license is not a license for every generated or dataset-derived file.** Copyright clearance and any data-access contract are distinct. These file-class decisions use the observed numerical contents and the stated provenance; they are not an assertion of formal permission from a third-party provider.

**Release-scope notice:** The independent CPU verification package can reproduce the headline results without the checkpoints or query-group metadata. The existing GitHub `v1.0.0` tag, its full Git history and the linked Zenodo deposition are **not** that rights-screened subset: the GitHub tagged tree includes the listed research assets. Deleting them from a later commit would not erase the earlier release or archive. Any corrective republication should use a separately screened source snapshot and explicitly identify the version and files available, rather than suggesting the original release was cleared. Distribution of fitted heads and derived metadata should be confirmed against rightsholder and source-data terms before presenting those artifacts as unconditionally reusable.

**No third-party datasets, upstream pretrained checkpoints, or bundled photographic images are redistributed.** The supplied ZIP's provenance labels are useful but insufficient to establish every source-image right and attribution obligation.

The withheld image bank was named `bundled_natural_image_bank.npz` and had SHA-256 `df2a6f0a0567e77c1d5753c47a90ac1ba862ecdfd38f7a858821c199e21dcb47`; it contained five downsampled 160×160 RGB assets. The controlled implementation uses that hash to refuse nonidentical image carriers. To rerun the benchmark exactly, obtain and use a copy of the **same** bank only when permission is established. Replacing carriers produces a *new* experiment and is not an exact replication.

**Rights and replay qualifications:** The MIT license covers original EUOT-VPR software only. The author-fitted heads and derived per-query records are preserved as evidence, and their provider-specific sharing restrictions should be independently reviewed. The five photographic assets remain excluded; obtaining their rights is necessary only to republish the image bank. Exact full image-level replay also requires the ordered MSLS manifest and matching SALAD model revision. Do not present permission as verified when only a broad upstream project license is known.
